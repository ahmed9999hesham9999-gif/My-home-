# نشر شقتي 3D على Vercel مع مزامنة (مجاني)

## الملفات (لازم تنرفع بنفس الشكل)
```
index.html
package.json
api/_db.js
api/ping.js
api/project.js
```

## الخطوات
1. **GitHub:** اعمل Repository جديد وارفع الملفات دي بنفس المجلدات (مجلد `api` لازم يفضل مجلد).
2. **Vercel:** Add New ← Project ← اختار الـ repo ← Framework Preset: **Other** ← Deploy.
3. **قاعدة البيانات:** من مشروعك في Vercel افتح **Storage** (أو Marketplace) ← اعمل **Upstash Redis** بالخطة المجانية وربطها بالمشروع. Vercel بيضيف لوحده المتغيرين `KV_REST_API_URL` و`KV_REST_API_TOKEN`.
4. **كلمة السر:** Settings ← Environment Variables ← ضيف `APP_PASSWORD` بكلمة سر قوية.
5. **أعد النشر:** Deployments ← آخر نشر ← Redeploy (عشان المتغيرات تتفعّل).
6. افتح الرابط. أول مرة بيطلب كلمة السر. فوق جنب العنوان لازم تشوف **● متزامن**.

## ازاي بيشتغل
- كل تعديل بيتحفظ في القاعدة، والتاني بيستقبله خلال حوالي 15 ثانية (وبيتوقف التحديث لما التبويب يكون مخفي).
- لو اتنين عدّلوا في نفس الوقت، آخر حفظ هو اللي يفضل.
- بيتحفظ نسخة احتياطية كل ساعة (بتتمسح بعد يومين) داخل Upstash باسم `apartment:bk:...`.
- حد أقصى حوالي 900 ك.ب للمشروع، فقلّل الصور.
- لو ظهرت "⚠ قاعدة البيانات غير مربوطة": راجع الخطوة 3 وأعد النشر.
- راقب استهلاك الأوامر من لوحة Upstash، لأن الخطة المجانية ليها حد شهري/يومي.
